# 💸 Expense Tracker (React)

A React-based Expense Tracker application currently under development. This
project is in its initial setup phase and will evolve into a full-featured
expense management tool.

> 🚧 **Project Status:** Initial Setup (No features implemented yet)

---

## 📌 About the Project

This project aims to help users:

- Track daily expenses
- Categorize spending
- Analyze financial habits

⚠️ _Note:_ The project is currently scaffolded and ready for development. Core
features are yet to be implemented.

---

## 🛠️ Tech Stack

- **Frontend:** React (Vite)
- **Language:** JavaScript
- **Linting & Formatting:** ESLint, Prettier
- **Git Hooks:** Husky + lint-staged

## 🚀 Getting Started

### 1. Clone the repository

```
git clone https://github.com/Amar7021/Expense-Tracker.git
```

### 2. Install dependencies

```
npm install
```

### 3. Run the development server

```
npm run dev
```
